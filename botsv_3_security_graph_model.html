图例

关系含义

有向边：源实体产生行为，目标实体被访问、影响或关联
证据边：Event 保留原始日志出处，避免语义压缩后丢证据

使用方式

拖动节点可以调整布局。点击节点或关系，会在右侧显示建模解释。搜索框可以高亮相关节点和边。

这个图不是具体攻击样本，而是 BOTSv3 这类多源日志最适合落地的统一建模骨架。

核心思想：Event 保证证据，Entity 形成攻击关系链
推荐视角：Identity → Endpoint → Network → Cloud / Message → Detection

说明面板

点击一个节点或关系

你会看到它表示的安全语义、典型 BOTSv3 sourcetype、以及它在攻击溯源里的作用。

最重要的不是 sourcetype 名字，而是它描述的实体关系：谁，在什么时候，通过什么手段，访问或影响了什么对象。
